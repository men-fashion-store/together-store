# Together

متجر عربي لعرض منتجات العناية واستقبال طلبات الدفع عند الاستلام. لا توجد بوابة دفع، ولا يتم تحويل العميل إلى واتساب.

## المزايا

- كتالوج منتجات وأقسام وعروض وسلة شراء.
- طلبات COD محفوظة في Firebase Realtime Database وتظهر في لوحة الإدارة.
- إدارة المنتجات والنصوص والألوان والعروض من لوحة التحكم.
- إدارة حالات الطلبات وتنبيهات صوتية وإشعارات متصفح عند فتح لوحة الإدارة.
- صور المنتجات تُرفع إلى Firebase Storage من حساب الإدارة.

## متطلبات Firebase

المشروع يستخدم Firebase Web SDK من CDN وبيانات المشروع المضمّنة في `index.html`.

1. فعّل Email/Password في Firebase Authentication.
2. استخدم حساب الإدارة المعتمد في Firebase Authentication وأكمل تحقق البريد الإلكتروني. لوحة الموقع والقواعد تقيد الإدارة بواسطة UID، وليس بمجرد معرفة البريد.
3. قواعد `database.rules.json` تقيد إدارة المتجر والطلبات بحساب الإدارة المعتمد، وتسمح للزائر بإرسال طلب COD فقط. تم نشر القواعد إلى قاعدة البيانات.
4. App Check مسجل باستخدام reCAPTCHA Enterprise؛ المفتاح العلني موجود في `APP_CHECK_SITE_KEY` داخل `index.html`. لا تضع أي Secret Key في المستودع. Enforcement لم يُفعّل بعد؛ فعّليه بعد اختبار الطلبات من الموقع المنشور.
5. رفع الصور يتطلب Firebase Storage. وحدة Storage في هذا المشروع تتطلب ربط حساب فوترة بخطة Blaze؛ لا تفعّلها قبل مراجعة التسعير وإضافة تنبيهات ميزانية. بعد ذلك انشر `storage.rules` وسجّل الدخول بحساب الإدارة الموثّق.

لا تستخدم Test mode ولا تضع أي Secret Key أو كلمة مرور في هذا المستودع. لم يُختبر بعد تدفق طلب حقيقي كامل في قاعدة البيانات. المشروع في وضع إطلاق تجريبي إلى أن يتم تأكيد دخول الإدارة وظهور طلب تجريبي في اللوحة.

## النشر على GitHub Pages

من إعدادات المستودع اختر **Pages → Deploy from a branch → main → /(root)**. رابط الموقع المتوقع `https://men-fashion-store.github.io/together-store/`. أضف نطاق `men-fashion-store.github.io` إلى Authorized domains في Firebase Authentication؛ وهو مضاف كذلك إلى مفتاح reCAPTCHA.

## حدود التشغيل الحالية

- تنبيهات الطلبات الحالية تعمل داخل لوحة الإدارة المفتوحة فقط؛ لا توجد إشعارات خلفية أو واتساب آلي.
- الأسعار والمخزون المرسلان من المتصفح ليسا مصدرًا موثوقًا، ولا يتم خصم المخزون تلقائيًا. يلزم Backend/Cloud Functions للتحقق الموثوق والحجز الذري للمخزون.
- Firebase Cloud Functions وخدمات Storage تتطلب خطة Blaze في إعدادات Firebase لهذا المشروع؛ يلزم موافقة مالك المشروع وربط الفوترة قبل نشرها، وقد تترتب رسوم حسب الاستخدام.
- بيانات المنتجات والأسعار وسياسات الشحن والاستبدال ووسائل التواصل يجب إدخالها ومراجعتها من مالك المتجر قبل استقبال عملاء حقيقيين.
- قبل الإطلاق، اختبر طلبًا كاملًا ببيانات اختبار غير حقيقية، وتأكد من ظهوره في لوحة الإدارة ثم احذف طلب الاختبار.
